This manual provides a single-source-of-truth reference explaining the 6 distinct layers of Meta's WhatsApp Business Cloud API, defining every identifier, and mapping both live accounts (SwissBlue Hospitality and GreenWood Manufacturing) currently integrated into WD Group Holding.

Section 1

The Core Mental Model: The 6-Layer Architecture

The main source of confusion when integrating Meta WhatsApp is that Meta uses six separate layers. They are strictly hierarchical and cannot be used interchangeably:

1

Meta Business Portfolio (Business Account)

The legal corporate organization in Meta (e.g., Abdallah El Fouly Foundation or شركة تصاميم الوطن). Owns all apps, billing, and accounts.

2

Meta App + System User (The Software Gateway)

The API gateway. The System User generates a permanent Access Token that authenticates your website backend.

3

WhatsApp Business Account (WABA)

The container account (e.g., SwissBlue LLC). Holds message templates, compliance status, and payment configuration.

4

Phone Number ID (The Crucial Target Endpoint!)

A numeric internal Meta object ID (e.g., 978544632005886). All API send calls MUST be addressed to this ID!

5

Display Phone Number (The Human Number)

The readable phone number (e.g., +966 50 707 4949) shown on client phones with the green checkmark.

6

Approved Message Templates

Pre-registered messages with variables ({{1}}, {{2}}) approved by Meta for utility, marketing, or order receipts.
